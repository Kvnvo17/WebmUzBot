1. Telegram'da @BotFather ga o'ting.
2. `/newbot` → nom va username kiriting.
3. Tokenni saqlab qo'ying.

## 2. Admin ID olish
@userinfobot ga o'ting va `/start` bosing — ID ni olasiz.
